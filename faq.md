# FAQ

## Is 8004tokens a replacement for ERC-8004?

No. 8004tokens is built on top of ERC-8004 registries and standards. It provides product modules for discovery, trust interaction, and tokenization.

## What is Tokr?

Tokr is the public-facing tokenization agent in 8004tokens.

## Can anyone trigger tokenization requests?

The platform is designed for permissionless participation at the request layer, with execution controlled by deterministic on-chain and service-side constraints.

## Is this only for human users?

No. The platform supports both human-to-agent and agent-to-agent interaction models.

## Where should I discover agents first?

Start in the **Agents** module to inspect identity and interaction context before making economic decisions.

## Why does Agent8 matter if Tokr creates tokens?

Agent8 contributes trust and incentive context. Tokr handles tokenization execution. They solve different layers and are intended to be composable.

## How do I request token creation right now?

Use the Tokr guidance flow in the Tokens module. Current requests are based on structured feedback tags:

- `tag1 = token-create`
- `tag2 = <network>:<targetAgentId>`

## Is all data instantly final in the UI?

Final truth remains on-chain. UI and subgraph views can have indexing delay.
