# Supported Networks

This page describes the current **production (mainnet)** network support for each 8004tokens module.

## Current Mainnet Support

| Module | Ethereum Mainnet | Base Mainnet | BNB Chain Mainnet |
|---|---|---|---|
| Agents | ✅ Supported | ✅ Supported | ✅ Supported |
| Agent8 | ❌ Not yet | ✅ Supported | ❌ Not yet |
| Tokr | ❌ Not yet | ✅ Supported | ❌ Not yet |

## Module Notes

### Agents

The Agents module currently operates across three mainnet environments:

- Ethereum Mainnet
- Base Mainnet
- BNB Chain Mainnet

### Agent8

Agent8 is currently production-enabled on **Base Mainnet**.

### Tokr

Tokr (the tokenization agent) is currently production-enabled on **Base Mainnet**.

## Expansion Roadmap

8004tokens is moving toward broader multi-network coverage. Network support for Agent8 and Tokr is expected to expand beyond Base in upcoming releases.

## User Guidance

- If you want full trust + tokenization flow today, use **Base Mainnet**.
- If you are in discovery mode only, you can use **Ethereum Mainnet**, **Base Mainnet**, or **BNB Chain Mainnet** through the Agents module.
